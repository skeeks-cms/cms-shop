# Применение справочников GPD

Текущая схема и правила: [GPD v2](gpd.md). Разделы с датами — история внедрения.

Опциональный поток включается через `gpdReceiver.referencesEnabled=true` после миграции `m260917_180000_gpd_reference_receiver`. По умолчанию выключен. Перед включением новых заданий применения включить этот поток: без него отсутствующие зависимости оставляют товар ожидающим. Старые команды v1 работают независимо.

`shop.gpd.references.sync` получает и применяет категории, бренды, коллекции, характеристики и их значения. Пустой payload, прежний ключ и привязка каталога текущего сайта. Исполняется в существующей очереди `gpd-apply`. Разделяет ресурс `shop:gpd:apply` с применением товаров, но имеет собственный dedup key. Нового worker или второго планировщика нет.

`shop_gpd_reference_connection` хранит отдельные курсор, фазу, поколение и идентичность источника. `shop_gpd_reference_state` хранит полученную и применённую версии, тип и исходный ID. JSON не копируется в эту таблицу. Получение использует тот же проверенный механизм атомарной фиксации курсора; применение — транзакцию записи модели вместе с подтверждением версии.

Новые задания обращаются только к v2; fallback к v1 отсутствует. Он ждёт применённой версии необходимого справочника. Отсутствующий вариант характеристики также означает ожидание. Следующее расписание повторяет попытку; полученная версия товара не теряется и не подтверждается преждевременно.

Бренды и коллекции с выключенным `is_sx_info_update` сохраняют локальные поля и изображения. Версия отмечается обработанной как защищённая. Повторное включение флага само по себе не сбрасывает подтверждённую версию; следующая версия источника будет применена.

Изображения в v2 обрабатываются как в v1: разделы, бренды и новые страны скачиваются; товары, коллекции и варианты характеристик используют прежний skeeksSuppliersApi.is_download_images (по умолчанию ссылки). Настройка gpd.imageMode скрыта и не используется. Карточки и изображения складов новые jobs пока не синхронизируют: используются заранее настроенные склады. Пустая основная картинка и пустая галерея очищают связи. Загрузка медиа выполняется до транзакции применения. Перед использованием кешированный ID файла перепроверяется, поскольку CMS удаляет невостребованные файлы.

Справочник, исключённый из API, сохраняется локально: он может использоваться товарами с защищёнными данными или локальными товарами. Удалённые варианты характеристик тоже не удаляются каскадно. Изменение типа уже существующей характеристики фиксируется как ошибка и требует отдельной миграции её значений.

Проверки: `tests/gpd-reference-receiver.php` — два префикса таблиц, независимость курсоров каталога и справочников, атомарность применения и безопасная повторная доставка. `tests/gpd-catalog-transport.php` проверяет URL отдельного потока и передачу GET-параметров без JSON-тела.

## Страны и единицы измерения

`shop.gpd.dictionaries.sync` с пустым payload получает полные `/v2/countries` и
`/v2/measures`. Курсоры и отдельные таблицы не нужны. Расписание — раз в сутки,
при подключении сайта запускается сразу. Очередь `gpd-apply`, общий ресурс
`shop:gpd:apply`, отдельный dedup `shop:gpd:dictionaries`.

`StableReferenceSync` создаёт только отсутствующие `CmsCountry` по `alpha2` и
`CmsMeasure` по `code`. Существующие поля и флаги стран не меняются. Для новых
стран изображения скачиваются как в v1. При применении товара,
бренда или характеристики неизвестный код запрашивается через v2 сразу;
если источник его не содержит, версия остаётся ожидающей. Ответ каждого
справочника кешируется только на время текущего экземпляра сервиса.

Пилот elitkras.ru: расписание 63, интервал 86400 с; первый запуск 402 проверил
283 записи (251 страна, 32 единицы), все уже существовали, ошибок 0.
HTTP-проверки подтвердили идентичность данных v1/v2 и ограничение v2 пилотом.
`tests/gpd-stable-reference-models.php /path/to/bootstrap.php` проверяет реальные
модели в откатываемой транзакции: создание, защиту локальных полей и флагов,
ожидание неизвестного кода, кеширование и отказ при дублирующихся кодах.
Запускать в согласованной тестовой БД; bootstrap должен создать Yii Application.
## Защита категорий

`cms_tree.is_sx_info_update` защищает категорию так же, как бренд или коллекцию:
при 0 не меняются название, описания, изображения и остальные поля GPD.
Защищённая версия подтверждается, поэтому товар может использовать эту категорию.
Повторное включение разрешает следующую версию; само переключение не создаёт событие.

Миграция CMS `m260917_210000__tree_gpd_sync_flag` устанавливает DEFAULT 1 для новых
записей и однократно выключает синхронизацию существующих `sx_id > 0` во всех
сайтах базы. Не выполнять этот UPDATE при запуске jobs. До запуска новых workers
применить миграцию и сбросить schema cache. Обновление пакетов без миграции не
считается завершённой установкой защиты. Старый `_updateTree` также уважает флаг.

Создание категории использует `shop\models\CmsSite`, поскольку связь `shopSite`
принадлежит модели магазина. Проверка `tests/gpd-category-models.php bootstrap.php`
охватывает создание, обновление, сохранение локальных данных, подтверждение защищённой
версии, использование категорией товара, повторное включение и legacy-команду.
На elitkras.ru миграция защитила две связанные категории; 13 проверок реальных
моделей выполнены с откатом временных записей.
